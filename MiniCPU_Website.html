Memory

Memory Map — pRAM & rRAM

pRAM — Program RAM (256 × 14 bit)

เก็บโปรแกรม 14-bit ต่อคำสั่ง โหลดเข้าผ่าน progIn ขณะ progLoad=1

0x00คำสั่งแรก (Instruction 0)
0x01Instruction 1
…… คำสั่งถัดไป
0xFFInstruction 255 (สูงสุด)

rRAM — Result RAM (256 × 8 bit)

เก็บผลลัพธ์และใช้เป็น Stack แบ่งโซนชัดเจน

0x00📤 Output[0] — ส่งออกเมื่อ result=1
…Output[1..14]
0x0F📤 Output[15] — ส่งออกตัวสุดท้าย
0x10พื้นที่ทั่วไป (indirect memory)
……
0xDFขอบพื้นที่ทั่วไป
0xE0📦 Stack bottom (ลึกสุด 32 ชั้น)
…Stack grows ↓ (full descending)
0xFF📦 Stack top — PUSH ครั้งแรก

Stack

Stack Simulator — PUSH / POP

Stack อยู่ใน rRAM[0xE0–0xFF] โตลงจากบน (Full Descending) SP ชี้ top-of-stack

accA =    SP = 0x00

คำอธิบาย

Stack ว่าง SP = 0x00
PUSH accA: SP ← SP−1, rRAM[SP] ← accA
POP accA: accA ← rRAM[SP], SP ← SP+1
ค่าแรกที่ push จะอยู่ที่ 0xFF
Special Instructions

GCD และ Fibonacci — คำสั่งพิเศษที่วนลูปในวงจร

GCD — หาร.ม. (opcode 11 1100)

อัลกอริทึม Euclidean แบบลบซ้ำ วนลูปใน GCD state จนกว่า gcdA = gcdB

Fibonacci — FIB(n) (opcode 11 1101)

วนลูปใน FIB state ผลลัพธ์ 16-bit เก็บที่ rRAM[0x0A:0x0B] (n ≤ 24)

ตัวอย่าง

โปรแกรมตัวอย่าง — Swap M ↔ N ผ่าน Stack

โปรแกรมนี้อ่าน M, N แล้วสลับค่ากันโดยใช้ Stack เก็บค่า SP ขณะมีข้อมูล 2 ชั้นไว้ที่ rRAM[0x02]
